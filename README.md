# PGRGachaSim 战双帕弥什模拟抽卡插件

> 基于 [gsuid_core](https://github.com/CM-Leo/gsuid_core) 框架的战双帕弥什（Punishing: Gray Raven）模拟抽卡插件。
> 抽卡材料与概率参照 [BWIKI 战双帕弥什「新抽卡模拟器」](https://wiki.biligame.com/zspms/%E6%96%B0%E6%8A%BD%E5%8D%A1%E6%A8%A1%E6%8B%9F%E5%99%A8)，卡池选择图使用库街区 wiki 的版本横图与角色资料。

## 功能

- **构造体研发**：基准 / 主题 / 命运主题研发，十连可能出 S/A/B 构造体、角色碎片、紫色意识、突破材料、经验材料、螺母箱
- **武器研发**：6/5/4/3 星武器、突破材料、螺母箱
- **辅助机研发**：S/A 级辅助机、支援单位经验/突破材料、技能元件、碎片、螺母箱
- **联动池**：联动成员狙击（BRS / 时崎狂三 / 但丁 / 维吉尔 / 2B / 9S / A2）与联动武器狙击
- **版本卡池选择**：`zs切换卡池` 发送版本横图网格（V4.8 ~ V2.10，26 个版本），每张图左右分别是该版本新角色的「主题 / 命运」编号；V3.5「幻寂鸣泣曲」为联动版本，拆成但丁、维吉尔两格
- **抽卡排名**：按天 / 周 / 月统计，排名依据为 **S 级角色 UP 次数**（UP 多、抽数少排前；UP 少、抽数多排后），时间以北京时间划分
- **头像**：抽卡结果图右上角显示 QQ 头像（下载缓存到本地，渲染时走 data URL，不请求外部）
- **图片渲染**：本地 Playwright 渲染，所有图标/版本图/立绘已下载到插件本地 `texture2d/`，渲染不请求外部资源
- 保底状态、每日次数、高稀有度记录、特征码落库；每日抽卡次数按北京时间自动刷新

## 安装

把 `PGRGachaSim` 目录放在 gsuid_core 的插件目录下：

```
gsuid_core/plugins/PGRGachaSim/
```

然后在 WebConsole 里确认插件已加载（或重启 core）。依赖 `jinja2`、`playwright`（gsuid_core 自带），并将 chromium 安装到 playwright。

## 命令

| 命令 | 功能 |
|------|------|
| `zs切换卡池` | 查看版本卡池图并选择卡池（版本角色主题/命运 + 基准/武器/辅助机），选一次 |
| `zs抽卡` | 使用已选卡池研发（默认主题研发，十连） |
| `zs抽卡基准` | 直接抽基准构造体研发（十连） |
| `zs抽卡武器` | 直接抽武器研发（十连） |
| `zs抽卡辅助机` | 直接抽辅助机研发（十连） |
| `zs抽卡百连` | 使用已选卡池百连（10 次十连，共 100 抽，需开启百连） |
| `zs抽卡百连武器` | 武器研发百连 |
| `zs抽卡百连辅助机` | 辅助机研发百连 |
| `zs抽卡排名` | 查看当天 UP 角色排名（可加 `周` / `月`，如 `zs抽卡排名周`） |
| `zs抽卡记录` | 查看高稀有度出货记录 |
| `zs更新卡池` | 从官方公告更新当期 UP（管理员） |
| `zs模拟绑定` | 绑定/查看 9 位特征码 |
| `zs模拟抽卡帮助` | 查看帮助 |

`pgr` 前缀等价（如 `pgr抽卡`）。

## 卡池数据

数据文件：`data/PGRGachaSim/gacha_data.json`（首次运行从插件内置
`PGRGachaSim/config/gacha_data.json` 复制）。角色、武器、辅助机、材料名单、
`versions` 版本列表和 `pools` 里的 `weights` / `up_s` / `up_a` / `up_w6` 都可直接编辑：

- `standard_s`：常驻（基准池）S 名单 = 全部 S 角色 - 当期 UP；基准池和主题池歪卡只从这里出
- `up_s`：当期 UP 角色名
- `up_a`：A 级 UP 角色名
- `up_w6`：武器池 6 星 UP 武器名
- `weights`：各类型权重（官方模拟器数值）
- `versions`：版本列表（name / icon / role），`zs切换卡池` 的版本图与编号来源于此

`切换卡池` 的选项 = 每个版本新角色的「主题 / 命运」+ 基准研发 + 武器研发 + 联动武器狙击 + 辅助机研发。
没有版本图的角色（如部分联动角色）只能在基准研发池中抽出。

当期 UP 变化时，管理员可以发 `zs更新卡池` 从官方公告自动刷新（也可以直接改 `up_s` / `standard_s`）。

改完后重启 core 或等待下次抽卡时重新加载。

## 排名口径

`zs抽卡排名`（天）/ `zs抽卡排名周` / `zs抽卡排名月`：

- 抽数：`PGRGachaDaily` 按北京时间日期汇总（全部池类型总和）
- UP 次数：`PGRGachaRecord` 中 `item_type=character` 且 `rarity=6` 的 `is_up` 记录数（只统计 S 级角色 UP，不含武器/A 级）
- 排序：UP 数降序 → 抽数升序 → user_id；0 UP 的用户保留在榜尾

## 配置

WebConsole「战双模拟抽卡」配置项：

| 配置 | 说明 |
|------|------|
| 模拟抽卡总开关 | 关闭后所有模拟抽卡命令不可用 |
| 每日抽卡次数上限 | 每用户每天每种池类型的次数上限（0 为无限），按北京时间刷新 |
| 主人无限抽取 | 主人（pm=0）不受每日次数限制 |
| 渲染失败时使用文本 | 图片渲染失败时回退纯文本 |
| 外置渲染开关 | 默认关闭；开启后使用「外置渲染地址」渲染，失败自动回退本地 |
| 百连功能开关 | 开启后可用百连命令（默认关闭） |
| 百连合并转发 | 百连结果使用合并转发（关闭则一条消息发多张图） |

## 资源与渲染

- `PGRGachaSim/texture2d/`：全部图标、版本横图、角色立绘、武器/辅助机图标（约 1024 个文件，均在本地，渲染不请求外部）
- 渲染：插件自带的本地 Playwright（不依赖 XWUID 外置渲染）；外置渲染仅在 WebConsole 打开开关时使用

## 说明

本插件是独立模拟器，不读取游戏数据、不逆向客户端；材料与概率来自 BWIKI
公开的官方模拟器页面，卡池图/角色资料来自库街区 wiki 公开页面，与真实服务器随机结果
不存在对应关系，仅用于娱乐。
