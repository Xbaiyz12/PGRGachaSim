## 功能

| 池类型 | 内容 |
|--------|------|
| 🧍 **构造体研发** | 基准 / 主题 / 命运主题，十连出 S/A/B 构造体、碎片、紫色意识、材料 |
| ⚔️ **武器研发** | 6/5/4/3 星武器 + 突破材料 |
| 🎮 **辅助机研发** | S/A 级辅助机 + 支援材料、技能元件、碎片 |
| 🎭 **联动池** | BRS / 时崎狂三 / 但丁 / 维吉尔 / 2B / 9S / A2 狙击 |

- **版本卡池选择**：`zs切换卡池` 发送 V4.8 ~ V2.10 共 26 个版本横图，选择后该版本的角色 / 武器 / 辅助机同时成为 UP
- **抽卡排名**：按天 / 周 / 月统计 S 级 UP 次数排名（北京时间）
- **本地渲染**：Playwright 本地截图，所有图标、立绘、版本图均在插件本地，不请求外部资源
- 保底、每日次数、高稀有度记录、特征码均落库

## 安装

将 `PGRGachaSim` 目录放入：

```
gsuid_core/plugins/PGRGachaSim/
```

在 WebConsole 确认加载（或重启 core）。依赖 `jinja2`、`playwright`（gsuid_core 自带），需安装 chromium：

```bash
playwright install chromium
```

## 命令

| 命令 | 功能 |
|------|------|
| `zs切换卡池` | 选择版本卡池（一次性） |

| `zs抽卡武器` | 武器研发十连 |

| `zs抽卡百连辅助机` | 辅助机百连 |
| `zs抽卡排名 [周/月]` | UP 排名（默认当天） |

| `zs更新卡池` | 从官方公告刷新当期 UP（管理员） |

| `zs模拟抽卡帮助` | 帮助 |

## 配置

| 配置 | 说明 |
|------|------|
| 模拟抽卡总开关 | 关闭后所有命令不可用 |
| 每日抽卡次数上限 | 每用户每天每池类型上限（0=无限），北京时间刷新 |
| 主人无限抽取 | pm=0 不受次数限制 |
| 百连功能开关 | 开启后可用百连命令 |
| 百连合并转发 | 百连结果使用合并转发 |
| 渲染失败时使用文本 | 图片渲染失败回退纯文本 |
| 外置渲染开关 | 开启后使用外置渲染地址，失败自动回退本地 |

## 卡池数据

数据文件：`data/PGRGachaSim/gacha_data.json`（首次运行从插件内置 `PGRGachaSim/config/gacha_data.json` 复制）。可编辑字段：

- `standard_s`：常驻 S 名单（基准 / 主题池歪卡来源）
- `up_s` / `up_a`：当期 UP 角色
- `up_w6`：武器池 6 星 UP
- `weights`：各类型权重
- `versions`：版本列表（`zs切换卡池` 的图与编号来源）

当期 UP 变化时，管理员发 `zs更新卡池` 自动刷新；改完后重启 core 或等待下次抽卡重载。

## 说明

本插件是独立模拟器，不读取游戏数据、不逆向客户端；材料与概率来自 BWIKI 公开的官方模拟器页面，卡池图 / 角色资料来自库街区 wiki，与真实服务器随机结果不存在对应关系，仅供娱乐。
